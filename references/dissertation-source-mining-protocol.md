# EMARX 学位论文文献库协议

本协议处理学位论文（[D]）引用的压减与替换。适用场景：马理论等人文学科论文中学位论文引用占比过高，或用户明确要求减少 [D] 引用。

## 一、基本原则

1. 学位论文不是一手来源。它价值在于其参考文献和引文线索，不在于其作者的二手归纳。
2. **禁止用"题目相近的专著或期刊"直接替换 [D] 引用**。题目相关不能证明该文献能支撑同一句话；这种替换制造虚假出处，比保留 [D] 更严重。
3. 压减 [D] 的正确方向是把引用追到更原始的来源，找不到就降级处理，而不是换个著录形式。

## 二、文献库方法

把每篇被引用的学位论文当作待挖掘的文献库，逐条处理：

1. **定位**：回到学位论文正文，确认它实际支撑了本文哪一句话；
2. **溯源**：查看该学位论文对应位置的参考文献和引文出处；
3. **改引**：优先把该句改引到学位论文所依据的原始文献、经典文献、专著或期刊论文，并核对新出处的页码；
4. **降级**：若该判断只是学位论文作者自己的归纳，没有可靠一手或期刊来源——保留作者归因（正文写明是某某的研究判断，脚注保留 [D] 著录），或删除该扩展判断；
5. **禁止**：不伪造替代出处、页码；不把学位论文作者观点冒充原始文献观点。

## 三、正文身份括注禁令

1. 正文不得出现"（XX大学硕士学位论文，2008年）""（XX博士学位论文）"这类插入语。文献身份信息只出现在脚注和参考文献中。
2. 文献综述中提到某研究时，写作者和观点即可（"王某某对……作了系统梳理"），不带学位类型和学校。

## 四、保留标准与报告

允许保留的 [D] 引用仅限：暂时没有可靠替代来源的具体研究评价或研究史说明，且已核对原文页码。

交付报告必须列出：

- 处理前 [D] 总数、处理后保留数；
- 每条保留项的位置和保留理由；
- 每条改引项的原出处和新出处；
- 被删除的判断及其原因。

## 五、失败信号

- 把 [D] 批量替换为同题名或同主题专著/期刊；
- 正文残留学位论文身份括注；
- 为压减 [D] 数量删除有实际论证作用的判断而不说明；
- 参考文献表保留了已无任何脚注对应的学位论文条目。
