# EMARX 经典文本向量检索协议

本协议规定经典文本向量库（马恩全集、习近平谈治国理政）在论文生产中的使用方式。

## 一、数据库与工具

本机经典文本向量库位于 `D:\BAOXUE\classics-rag\`（可用环境变量 `CLASSICS_RAG_HOME` 覆盖）：

| 库 | 内容 | 定位粒度 | collection |
|---|---|---|---|
| `mega-rag/` | 马克思恩格斯全集（约 34,540 页） | 卷次+页码 | `marx_engels` |
| `xjp-zglz/` | 习近平谈治国理政五卷+文化思想学习纲要 | 卷次+篇章+页码区间 | `xjp_zglz` |

统一检索入口（技能内脚本）：

```bash
# 双库检索
python scripts/classics_search.py "精神生产与物质生产" --db both --top-k 8
# 限定库/卷
python scripts/classics_search.py "宗教批判" --db marx --volume 3
# 按地址取马恩原文
python scripts/classics_search.py --fetch marx 42 368
# 库状态
python scripts/classics_search.py --info
```

向量库本体不进技能仓库（体积约 900MB+）。库缺失时脚本会报错，AI 应提示用户库的预期位置，不得伪造检索结果。

## 二、什么时候使用

1. **核验经典原句**：正文要引用马恩或习近平著作原句时，先用向量检索定位卷页，再回原文核验文字；
2. **寻找理论源头**：论证需要经典支撑时，检索相关概念的原始论述；
3. **研究综述**：查某概念在经典文本中的论述史；
4. **政治合规核验**：涉及党的创新理论表述时，回到治国理政原文核对标准提法。

## 三、使用纪律

1. **向量检索只是定位工具**。命中段落必须回到原文（PDF 页/纸本）核验文字和页码后，才能写进正文。禁止把检索返回的文本直接当作核验过的引文。
2. **相关度阈值**：本库 bge 余弦分数整体偏低，实测有效命中多在 0.35—0.45 区间。score ≥ 0.35 的命中优先核验；0.25—0.35 仅作线索；低于 0.25 基本不相关。完全没有高相关命中时如实说明"经典文本中未检索到直接论述"，不得强行附会。
3. **著录规范**：马恩引文按 `footnote-engineering-protocol.md` 的书级著录（马克思恩格斯全集: 第X卷[M]. 北京: 人民出版社, 年: 页码）；治国理政引文同样以书为主体（习近平. 习近平谈治国理政: 第X卷[M]. 北京: 外文出版社, 年: 页码）。
4. **一句话一个脚注**的规则对经典引文同样适用。
5. 版本年份以工作空间实际使用版本为准，不照抄示例。

## 四、失败信号

- 把向量库返回文本不经核验直接写进正文；
- 编造检索结果或页码；
- 检索不到就编造经典引文；
- 引用马恩只写"马克思指出"而不给卷次页码。
